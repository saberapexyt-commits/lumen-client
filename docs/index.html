Stop guessing which file to download

Search Modrinth and CurseForge from inside the launcher. Lumen only offers files that explicitly support your Minecraft version and mod loader.

The right version, every time

The newest release of a mod is often built for a different Minecraft version. Lumen never assumes. It checks the exact version and loader of your profile before it installs anything.

  • Fabric, Quilt, Forge and NeoForge
  • Required dependencies added automatically, optional ones only if you tick them
  • Warnings for conflicts, and for mods that need a manual download
  • Pick a different version yourself when you want to

Keep a vanilla setup, a PvP setup and a big modpack side by side. Each profile has its own Minecraft version, loader, mods, configs and worlds.

  • Enable, disable, update and remove mods without hunting for jar files
  • Removed mods go to a trash folder, never silently deleted
  • Import Modrinth and CurseForge modpacks, export and back up your own
  • A health check flags missing dependencies and wrong-loader mods

Reliable by design

Every download is checked against its checksum. Installs are staged first, so a failed download never leaves you with half a mod. You can cancel and retry at any point.

  • Game files and Java come straight from Mojang. You never install Java yourself
  • Clear error messages and a live console for the game output
  • Updates arrive inside the launcher and install silently

FAQ

Good to know

Straight answers, including the limits.

Do I need to own Minecraft?

Yes. Lumen signs in with the Microsoft account that owns Minecraft: Java Edition. It does not provide the game or any way around buying it.

Is my Microsoft password safe?

Lumen never sees it. You sign in on Microsoft's own page, and the launcher keeps only an encrypted sign-in token on your PC. See the Privacy Policy.

Is it affiliated with Minecraft, Modrinth or CurseForge?

No. It is an independent project. Mods are downloaded through the official Modrinth and CurseForge APIs and stay under their authors' licences. Authors who disable third-party downloads are respected, and you are pointed to the source instead.

Does it have a FPS counter, HUD or in-game overlay?

Not yet. Those have to run inside Minecraft, so they need a companion mod, which is planned but not built. Today you get a one-click performance pack of existing open-source mods, JVM presets and quick FPS and render-distance settings.

Which platforms are supported?

Windows 10 and 11 right now. The code is written to be portable, but only Windows has been tested.
